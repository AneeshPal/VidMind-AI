# VidMind – AI-Powered YouTube Assistant

VidMind is an AI-powered Chrome browser extension that allows users to interact with YouTube videos through a conversational chatbot.

Users can ask questions, summarize lectures, extract important concepts, and understand video content using Retrieval-Augmented Generation (RAG).

## Tech Stack

- React
- Chrome Extension Manifest V3
- Python
- FastAPI
- LangChain
- OpenAI API
- FAISS
- MongoDB (planned)

## Project Structure

```text
VidMind/
├── extension/
├── backend/
└── docs/
```

## Planned Features

- Ask questions about the currently playing YouTube video.
- AI-powered video summarization.
- Context-aware follow-up questions.
- Timestamp-based answers.
- Generate notes and quizzes.
